# beta.28 功能（白話版）

1. **1 ms Telemetry**：最快可要求每 1 ms 取樣，但畫面不會跟著每 1 ms 重畫。
2. **Adaptive Refresh**：背景／前景使用不同刷新節奏。
3. **Process Memory**：顯示 Working Set 與 Private Memory。
4. **Commit Δ**：看最近哪個程式變大最快。
5. **Leak Indicator**：短時間快速增加時標記「可能快速增長」。
6. **Commit ETA**：依近期趨勢估算剩餘時間；只當趨勢提示。
7. **Page File / Commit Headroom**：顯示還有多少緩衝。
8. **Emergency Status**：壓力太高時切換到注意／危險提示。
9. **Safe Close Advisor**：優先建議正常關閉大型一般程式，不亂殺系統程式。
10. **Flight Recorder**：背景保留近期記憶體樣本。
11. **Incident Bundle**：一鍵匯出事故資料到桌面。
12. **Notification Center**：新功能、更新與警告集中顯示。
13. **Update Center**：檢查 GitHub Releases。
14. **Desktop Notification**：發現新版可顯示 Windows 通知；目前是 polling，不假裝 true push。
15. **Beginner Log**：Log 先翻成白話再顯示。
16. **Open Log Folder**：按鈕直接開真正 Log 目錄。
17. **Default Maximized**：啟動直接最大化。
18. **Real Install / Repair / Uninstall**：真正複製程式、建立捷徑、登錄解除安裝資訊。
19. **Portable EXE**：Release 同時提供免安裝 EXE。
20. **SHA-256**：Release 附檔案雜湊方便驗證。
